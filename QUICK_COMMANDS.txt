==========================================
     DRONE SD CARD - QUICK COMMANDS
==========================================

📍 ALWAYS START HERE:
cd ~/Documents/workspace/projects/wheeldogg_channel


📥 IMPORT FOOTAGE
-----------------
# Smart import (auto-detects dates) - RECOMMENDED
./scripts/drone-import-smart.sh

# Direct to Dropbox (when Mac is full)
./scripts/drone-import-dropbox.sh "2025-11-10_Beach"


🗑️ CLEAN SD CARD
----------------
# See what's on SD card
./scripts/drone-cleanup-sd.sh

# Delete specific date (e.g., Nov 9)
./scripts/drone-cleanup-sd.sh 20251109


📊 CHECK STATUS
--------------
# View all projects
./scripts/drone-summary.sh

# Specific project
./scripts/drone-summary.sh "Beach_Flight"


📸 PHOTOS FROM VIDEO
--------------------
# Last 5 frames of clip 0669
./scripts/drone-extract-frames.sh 0669

# Specific times
./scripts/drone-extract-frames.sh 0669 --at 0:05,1:23

# Every frame in the last 2 seconds
./scripts/drone-extract-frames.sh 0669 --last-seconds 2

# → lands in PHOTOS/FROM_VIDEO/


🔧 FIX ISSUES
------------
# Fix mixed dates in folder
./scripts/fix-mixed-dates.sh


==========================================
        TYPICAL WORKFLOW
==========================================

1. Insert SD card

2. Import footage:
   ./scripts/drone-import-smart.sh
   → Choose option 1 (auto-detect)

3. Wait for Dropbox sync (check menu bar)

4. Clean SD card:
   ./scripts/drone-cleanup-sd.sh 20251109

5. Make Dropbox online-only (save Mac space):
   → Right-click folders in Finder
   → "Make Available Online-only"
